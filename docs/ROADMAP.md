# VidhiSangh — Delivery Roadmap

> **Current plan (27 September 2026):** use [APP_AUDIT_AND_ROADMAP.md](APP_AUDIT_AND_ROADMAP.md) for priorities, acceptance criteria, effort, and the next 12 months. This file is retained as implementation history and contains stale completion claims.

This platform is built **incrementally on a shared foundation**. Phase 1 is
implemented and verified; later phases layer functional modules onto it. Every
module follows the same contract: DDD bounded context (`models → schemas →
repository → service → router`), RBAC-guarded API, migrations, tests, and a
lazy-loaded Angular feature area.

Legend: ✅ done · 🚧 in progress · ⬜ planned

## Engineering standards (every phase)
- ≥ 90% unit-test coverage for business logic; integration + e2e tests.
- Strict typing (mypy strict, TS strict) and linting (Ruff, Angular lint) in CI.
- A migration for every schema change; API docs auto-generated.
- Security review + code review required to merge.
- Structured logging, metrics, health checks, tracing on every module.
